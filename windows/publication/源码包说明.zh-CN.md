# 映绘 Yinghui 0.4.5 源码包说明

此 ZIP 包含 Windows C++/Qt 程序、测试与脚本，以及原有 macOS Swift/Xcode 工程。仓库原有 `LICENSE` 为 MIT，保留 `Wonder Assembly LLC` 版权声明。Windows 版本入口见 `windows/README.md`、`windows/CMakeLists.txt`；中文用户说明见 `windows/publication/使用手册.zh-CN.md`。原始 macOS 工程说明见根目录 `README.md`。

源码包**不包含**运行库、模型权重、编译输出、用户图片、聊天记录、Windows 凭据或 API 密钥。这能让代码仓库保持适合托管与审阅的体积。交付目录中的完整安装包另含离线模型，其许可证不随源码 MIT 自动改变。

## Windows 构建

准备 Windows 10/11 x64、Visual Studio 2022 的 C++ 桌面工具与 Windows SDK、CMake/Ninja、Python 3。Qt 6.12 可通过 `python windows/scripts/bootstrap.py` 放进 `windows/.tools`，也可把 `COMPOSITOR_QT_ROOT` 指到已有 SDK。随后在仓库根目录运行：

```powershell
python windows/scripts/build.py configure
python windows/scripts/build.py build
python windows/scripts/build.py test
```

`windows/scripts/bootstrap_embedded_ai.py` 与 `bootstrap_qwen38.py` 会获取看图模型和对应的随包推理运行库；`bootstrap_embedded_image.py` 准备轻量生图环境。`bootstrap_models.py` 准备本机对象识别等验证资产。脚本使用固定来源与摘要；下载体积很大，请先核对对应模型许可。若需要 Qwen-Image-2.1 私有离线图片包，`windows/scripts/import_comfy_pack.py` 要求开发者自己提供具备对应模型和运行环境的 ComfyUI，并明确传入来源与输出位置。源码 ZIP 本身不等于可离线编译全量 AI 安装器。

Windows CI 工作流在 `.github/workflows/windows.yml`。macOS 工程用 `Compositor.xcodeproj` 与 `CompositorTests`；macOS 与 Windows 共用项目格式概念，但界面和构建链独立。更详细的格式兼容说明在 `docs/project-format.md` 与 `windows/README.md`。
