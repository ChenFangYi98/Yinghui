# 映绘 Yinghui 0.4.5 开源交付目录

这个文件夹把安装包、源码包、中文使用手册、功能说明和公众号文章放在一起。它是**准备公开发布的文件集合**；代码和文章尚未自动上传到网站。

| 文件 | 用途 |
|---|---|
| `Yinghui-Windows-0.4.5-x64-Portable/` | 当前交付目录内的免安装文件夹，直接双击里面的 `Yinghui.exe`；整夹复制到其他 Windows 电脑也可使用。 |
| `Yinghui-Windows-0.4.5-x64-Portable-with-Source.zip` | **源码和免安装可运行版合在一个文件。** 完整解压后进入便携版文件夹，双击 `Yinghui.exe`；源码 ZIP 在压缩包根目录。无需运行安装器。 |
| `Yinghui-Windows-0.4.5-x64-Offline-Installer.zip` | **一个文件下载完整离线安装包。** 解压后双击里面的 `Setup.exe`；安装器与全部分卷已在 ZIP 中。 |
| `Yinghui-Windows-0.4.5-x64-Setup.exe` 与所有 `Setup-数字.bin` | 完整离线 Windows 安装包。必须一起下载并放在同一文件夹，双击 `Setup.exe` 安装；不要只分享 `.exe`。 |
| `Yinghui-Source-0.4.5.zip` | 可公开托管的源码，包含 Windows C++/Qt 与原 macOS Swift 工程、测试、构建脚本、项目原有 MIT `LICENSE`。不包含个人照片、API 密钥、模型权重、编译产物和用户设置。 |
| `使用手册.zh-CN.html`、`.md` | 面向第一次修图的用户：安装、常见操作、AI、图层、保存、导出、故障排查。双击 HTML 即可在浏览器阅读；Markdown 方便修改。 |
| `功能说明.zh-CN.html`、`.md` | 功能边界、设计方式、测试证据和未完成事项，适合放在仓库或下载页。 |
| `公众号文章-映绘0.4.5.zh-CN.md`、`宣传配图-软件界面.png` | 可改写发布的公众号稿与实际软件截图。发布前把文末占位文字替换为真实下载、源码链接。 |
| `开源与第三方许可说明.zh-CN.md` | 区分应用源码许可与随包模型许可。 |
| `源码包说明.zh-CN.md` | 开发者的源码目录、Windows 构建与离线模型准备说明。 |
| `SHA256SUMS.txt`、`交付清单.json` | 最终安装分卷、源码和文档的文件大小与 SHA-256，可核对传输完整性。 |

软件源码沿用仓库的 MIT 许可并保留原版权声明。**完整安装包不等同于“所有组件 MIT”**：其中 Qwen-Image-2.1 图片权重依据 Qwen Research License 只授权研究与评估，商用需另行取得授权；ComfyUI、Qt 和其他模型也有独立许可。源码包和安装包可以分别发布，并附上相应的许可证与署名。

完整离线数据约 39 GiB。现用 Inno Setup 对超过约 4.2 GB 的安装数据必须分卷，Windows 实测也拒绝启动附有超过 5 GB 数据的普通 EXE。因此此版本无法可靠地做成一个直接双击的离线安装 EXE。上面的单 ZIP 可以做到只下载一个文件，但须先解压；若需要一个小 EXE 自动联网下载模型，还需要稳定的公开下载地址和网络安装流程。

使用完整安装版时，Windows 10 22H2 / Windows 11 x64，安装目录建议至少留 45 GB。安装包和已安装程序都保存在同一磁盘时，建议留 90 GB 以上。大看图模型适合充足内存与显存的电脑，低配置请在模型设置中切换 2B。系统驱动、模型质量与复杂画面的判断仍有机器差异。

若使用单 ZIP 并在同一磁盘**同时保留 ZIP、解压后的分卷和已安装程序**，峰值空间建议至少 125 GB。空间较紧时，可在完整解压并确认 Setup.exe 与 21 个分卷齐全后删除 ZIP，再开始安装。

免安装便携版与完整安装版包含同一套本地模型。便携 ZIP 约 41 GiB，解压后约 41 GiB；在同一磁盘同时保留两者时建议预留至少 85 GB。解压完成后可以删除 ZIP，只保留便携文件夹。源码 ZIP 可以单独下载，也已放入便携包；源码需自行构建，直接运行的是其中的 Windows 程序文件夹。

本次安装程序**未签署代码签名证书**，Windows 可能提示“未知发布者”。请从可信的发布位置取得完整分卷，先使用 `SHA256SUMS.txt` 核对文件，再决定是否安装。0.4.5 应用与本地模型已在 Windows 11 实测；同一安装脚本制作的轻量测试包通过了独立安装、启动和卸载。**这个 41.7 GB 完整安装包没有在干净系统上再次完整安装验证**，Windows 10 和更多硬件仍需要后续验收。

打开《使用手册》按“五分钟修好一张照片”操作；想继续改程序，看《源码包说明》和 ZIP 里的 `windows/README.md`。发布时在开源仓库说明中保留原 MIT 声明、第三方告知和本次版本的测试边界。
