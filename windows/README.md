# 映绘 Yinghui Windows 0.4.5

0.4.5增加Qwen3.8-27B多模态看图模型，保留轻量2B；修复本地代理干扰和重启后连接失效，持续检测服务状态。
各看图型号与图片模型分别保存运行参数，开放独立环境和开发者运行库。大致位置模式结合整图定位对象，再识别精确边缘并交给图片引擎。
见 [0.4.5 实施记录](IMPLEMENTATION-0.4.5.zh-CN.md) 和 [验证记录](VALIDATION-0.4.5.md)。完整便携目录包含新增权重；旧版完整包可使用包含权重的更新ZIP。

0.4.4 统一助手输入框，模型设置中通过勾选实现文字工具、图片生成 / 编辑或双模型协作。
仅圈选 / 全部区域在助手页直接选择；未启用的模型不会调用。
已有 0.4.3 完整版可使用小体积更新 ZIP，不必重复复制权重。见 [0.4.4 验证记录](VALIDATION-0.4.4.md)。

0.4.3 在原有千问多模态助手和轻量图片引擎之外，加入从本机复制的 Qwen-Image-2.1 INT8 生图 / 改图离线包。
图片包自带隔离的 Python / PyTorch / Comfy 核心，软件按需启动，连续任务保留模型缓存；不依赖原来的 ComfyUI 服务。
文字助手和图片引擎分别选择，模型中心、操作日志分别显示。增加可恢复的开发者脚本编辑页，更新名称和 Windows 图标。
Qwen 2.1 限研究 / 评估使用，商用需另获授权。用法见 [本地 AI 指南](LOCAL-AI.zh-CN.md) 和 [0.4.3 实施记录](IMPLEMENTATION-0.4.3.zh-CN.md)。

这是在独立 `windows/` 目录实现的 C++20 / Qt 6.12 Widgets Windows 应用。
原有 Swift / Xcode 工程保留，仍读取、保存目录式 v11 项目。
Windows 新项目使用 ZIP64 单文件 `.comp` v15，保留图层锁定、区域记忆、局部变形和实际工具记录。
继续读取 v12–14 单文件和 v1–11 目录项目；旧项目首次保存默认另存新版。

## 运行

解压完整便携 ZIP，运行 `Yinghui.exe`；或在安装文件夹运行 `*-Setup.exe` 安装到当前用户。
0.4.5 完整安装器与所有同名前缀的 `.bin` 数据文件必须放在同一目录。完整程序约 44.2 GB，请至少为安装目录预留 45 GB；若安装包也保留在同一磁盘，建议留出 90 GB。已有 0.4.3／0.4.4 完整版也可使用约 17.4 GB 的更新 ZIP。
已有配置、Windows 凭据和恢复数据沿用原来的 Compositor 存储位置，无需重新填写。
默认简体中文；“设置”菜单可切换英文，下次启动生效。
附带 Noto Sans SC 中文回退字体及其 OFL 许可证，无需安装字体到系统。
系统边界：Windows 10 22H2 / Windows 11 x64，8 位 sRGB。
原生 Windows 11 已构建和运行；Windows 10 和无开发环境虚拟机仍需发布验收。

## 简单修图与 AI

默认简单模式，常驻中文想法输入、圈选、涂抹标记、点选对象、撤销、版本和导出。
首页提供打开照片、离线示例、文字、拼图和海报。
从右侧“轻松修图”完成自动优化、十二款滤镜、强度调整、中文标题和导出。
效果先预览再应用，参数仍可在专业模式修改；有选区时明确显示局部范围。
六款拼图和六款海报保留图片、文字与背景图层，可以替换图片。
菜单提供六个简短教程；Ctrl+Shift+W 随时切换工作区，文档保持一致。

专业模式提供调整栈、色阶、曲线、历史记录、锁定、选区羽化、魔棒容差及添加／减去选区。
移动工具的角点可缩放，上方手柄可旋转，Shift 保持比例或按 15° 旋转；Ctrl+T 精确输入。
Ctrl+Shift+L 锁定／解锁，锁定规则也覆盖 AI 操作。Ctrl+K 搜索登记的编辑命令。
导出向导提供分享、透明图片、打印和 PSD 入口；批量处理把结果写到新建的独立子目录。

右侧“AI 助手”支持教学与修改，新安装默认内置千问；已有默认选择保留。打开“模型中心”
分别设置文字助手和图片引擎。云端连接填写凭据、获取账户模型；也可使用 Ollama、LM Studio、
DeepSeek、通义、豆包、OpenAI 兼容服务，以及 Claude Messages 和 Gemini 原生接口。
对话与图片连接分别选择；各能力声明、接口可达与实际测试状态分别显示。
本机 Ollama 默认 `http://127.0.0.1:11434`；LM Studio 默认 `http://127.0.0.1:1234/v1`。
这些外部本地服务由用户安装；内置模型和运行库随完整安装包提供。本地失败不会自动转发云端。

统一助手连接 OpenAI Images、Gemini 图片、百炼万相或 ComfyUI，按连接能力使用
生图、选区重绘、涂抹消除、背景替换和扩图。ComfyUI 内置生成／重绘工作流，
高级用户可以导入 API 工作流并映射输入、输出节点。
局部编辑仅合成原始选区内像素，支持透明像素替换，结果为独立图层；扩图保留
可见、可编辑的原图层，并固定原有空间效果的处理范围，新内容仅显示在新增区域。
自动抠图尚未单独适配，背景处理使用选区与蒙版向导。

AI 默认在副本执行，通过校验并持久保存版本后自动应用，可一次撤销；也能选择先预览。
切换或修改文档、改变选区会取消过期结果；平移、缩放与保存不会误取消。
上下文包含真实参数、图层、选区坐标、标注图和最近工具结果。明确数值由本机解析与校验，
同区域沿用原节点，支持中文数字、增加／设置、EV、百分比和连续修改。
0.3.1支持多条精确调色按顺序组成一次修改、全角数字和变暗；任一步无效时整组不提交。
明确作用范围沿用到后续调色，参数保留要求冲突、负数方向歧义和混合未解析步骤会明确提示。
小选区发送原始清晰度局部图及其标注图，附原图坐标映射；不再放大整图缩略图冒充局部细节。
助手只使用登记的编辑命令，不执行脚本或自行保存文件；默认最多四轮、二十条命令、两次图片请求，可在执行设置中调整。
可关闭附带缩略图；发送画面最长边不超过 2048 px，重新编码，不附带路径或 EXIF。
密钥仅存入 Windows 凭据管理器，项目、配置导出和安装包均不包含密钥。
配置、默认连接和模型本机持久保存；空密钥框沿用凭据，删除使用独立按钮。
启动和配置改变后在后台短回复检测，不附图、不执行工具；图片连接不自动生图，失败不清空配置。
聊天不写入项目。连接可达、对话回复与各项图片能力分别验证。

模型哈希、来源版本和验证项在 models/validation.json；推理正确性与人像编辑质量分别验收。

## 编辑与保存

- 文件 → 打开支持 PNG、JPEG、BMP、WebP、TIFF、GIF、SVG、PSD、PSB 和 `.comp`。
  旧版目录项目通过“导入旧版项目文件夹”打开，另存为单文件项目。
- 各格式解码后使用同一份图层、绘图和调色代码。
- 当前图层右侧点击 `+` 添加“基本调色”、色阶、曲线或反相。
  亮度、对比度、曝光、高光、阴影、白场、黑场、色温、色调、色相、
  饱和度、自然饱和度、三段色彩平衡、黑白、渐变映射、纹理、清晰度、
  去朦胧、锐化、降噪、暗角、颗粒和模糊均保存为参数。
- 调整栈从上到下执行，可以移动、关闭、删除和重置；“添加调整图层”作用于下方内容。
  有选区时新增调整使用局部蒙版。原始像素与参数分别保存。
- 滑杆拖动合并为一个撤销步骤，Esc 取消未提交操作；复选框显示调整前内容。
- 画笔 B、橡皮 E、仿制 S（Alt+单击取样）、修复 J、模糊、渐变 G、形状 U、
  文字 T、裁剪 C、套索 L、魔棒 W、矩形选区 M。
- 文字使用 Windows 输入法，Ctrl+Enter 完成，Esc 取消；双击文字图层重新编辑。
- 移动 V；Ctrl+T 打开尺寸、位置、旋转和翻转对话框；空格拖动画布、滚轮缩放。
  Ctrl+0 适合窗口。选择菜单支持全选、反选和取消选择。
- 图层菜单支持分组、复制、排序、蒙版、剪贴蒙版和六种图层效果。
  分组可选择旧版混合、穿透或隔离；24 种混合模式在图层面板修改。
  蒙版可启用、关闭或解除链接后独立移动；画笔和渐变均遵守选区。
- Ctrl+C / X / V 复制、剪切和粘贴；Delete 清除选区像素。
  X 交换前景与背景色，D 恢复黑白。渐变映射支持自选暗部和亮部颜色。
- Ctrl+S 保存完整可编辑 `.comp`；“导出”生成 TIFF、PNG、JPEG、BMP、WebP 或 PSD。
  导出不替代项目保存。每 60 秒为修改文档保存恢复副本，文件菜单可恢复。
- 每次 AI 提交前持久保存前后版本，手动事务结束后后台记录；共享 PNG 去重。
  版本面板支持比较、命名和分支恢复，默认100个自动状态／项目及10 GiB本机预算。
  文件菜单“保存时包含历史版本”可把历史装入项目；默认仅保存当前完整状态。

## 格式转换边界

TIFF 支持无压缩、LZW、Deflate、PackBits、JPEG 等 libtiff 编解码器，导出使用
LZW 或 Deflate、非关联透明度、DPI 与 sRGB ICC。16 位输入转换为 8 位并报告，
多页只导入首页。GIF 只导入首帧；SVG 按指定尺寸栅格化。

PSD / PSB 只接收 8 位 RGB。支持原始、RLE、ZIP 通道、图层、分组、像素蒙版及
常用混合模式。色阶、曲线、反相调整层可以转换；无法解析的 Photoshop 调整、效果、
混合描述符，以及与旧版行为不同的剪贴堆栈，以合成画面导入并报告。
文字和智能对象使用已有像素，完整 Photoshop 往返
不在首版范围。PSD 导出保留基础像素图层、分组、蒙版、透明度与混合模式；
文字、形状、图层参数和效果烘焙；调整层、剪贴蒙版和旧版组影响的底部图层栈合并，上方
图层继续分层。导出前显示转换报告。真实 Photoshop 应用中的往返验收仍需执行。

旧版色阶、曲线、曝光、色相/饱和度、渐变映射、颗粒、黑白、色彩平衡、反相、噪声及模糊
设置保留；色相/饱和度复用原有色彩查找表算法，包含色段、范围反转和着色。
Apple Core Image 模糊使用跨平台近似算法，外观尚未达到逐像素一致性。
旧版元数据保留在 `legacy` 节点，可关闭或增加新的调色节点。

处理和合成目前由可取消的 CPU 浮点管线执行，Direct3D 11 负责原生画布显示，
硬件不可用时尝试 WARP，之后回退 Qt 绘制。未宣称 GPU 调色计算已完成。
最终预览最多 2048 px，拖动预览最多 1024 px，导出使用原始分辨率和同一处理顺序；
最终预览先按原尺寸计算再缩小，拖动期间的快速预览仍有采样误差；画布当前最多显示2048像素预览，
版本比较另提供100%局部细节。尚不支持 16/32 位编辑、RAW、CMYK、动画或完整人像美颜。
瘦臂与局部变形已提供受限功能，完整液化、智能对象、路径文字、多画板等专业能力尚未实现。
手动版本队列尚未落盘时异常退出仍可能丢失尾部记录，当前不宣称完整事务恢复日志已完成。
AI 图像处理需要另行配置图片服务，服务质量取决于所选模型。

## 构建与验证

安装 Python 3、Visual Studio 2022 的“使用 C++ 的桌面开发”（Windows SDK、CMake、Ninja）。

```powershell
python windows/scripts/bootstrap.py
py -3.12 -m venv windows/.tools/model-export
windows/.tools/model-export/Scripts/python.exe -m pip install torch==2.14.1 torchvision==0.29.1 --index-url https://download.pytorch.org/whl/cpu
windows/.tools/model-export/Scripts/python.exe -m pip install -r windows/scripts/model-export-requirements.txt
windows/.tools/model-export/Scripts/python.exe windows/scripts/bootstrap_models.py
python windows/scripts/build.py configure
python windows/scripts/build.py build
python windows/scripts/build.py test
python windows/scripts/build.py package
```

导出模型使用Python 3.12环境；这一步只用于开发和打包，最终用户不需要Python。
也可以设置 `COMPOSITOR_QT_ROOT` 指向已有 Qt 6.12.0 MSVC x64 SDK。
依赖首次构建下载，Qt 下载验证官方 SHA-256。构建产物位于 `windows/out/release`，
发布文件位于 `windows/dist`。打包包含 Qt 插件、中文翻译、MSVC 运行库和许可证，
在清空开发工具 PATH 后执行启动测试。安装包构建使用经过签名验证的 Inno Setup。
中文 MSVC 编译日志由 `scripts/msvc.py` 规范化，确保 Ninja 能识别头文件依赖。

CTest 包含像素、格式、项目、撤销和原生界面测试；UI 测试提交中文输入法事件并
执行 TIFF → 绘图 → 调色 → 中文文字 → 保存重开 → TIFF / PSD 流程。
Direct3D 回读与 CPU 图像比较允许 1 个字节误差。

独立格式检查和性能基准：

```powershell
python -m pip install -r windows/tests/requirements.txt
python windows/scripts/validate_formats.py
$env:PATH = "$PWD/windows/.tools/Qt/bin;$env:PATH"
windows/out/release/compositor_benchmark.exe windows/out/benchmark.json -platform offscreen
```

验证结果和本机性能见 [VALIDATION.md](VALIDATION.md)。Windows CI 自动运行构建、测试、
独立格式检查、性能基准与打包，并上传产物。
干净系统安装、真实输入法候选窗口、数位板和真实 Photoshop 样本矩阵的结果不能
由这些自动测试替代。
