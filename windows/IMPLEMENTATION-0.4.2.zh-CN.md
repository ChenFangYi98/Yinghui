# 0.4.2 实施记录

本版增加随安装包提供的离线千问多模态助手与独立生图 / 重绘模型，拆分模型中心和操作日志窗口，保留已有云端与 ComfyUI 连接。项目格式保持 v15。

- `EmbeddedAI` 管理模型检查、隐藏进程、随机本机端口、临时鉴权、后台加载、设备选择和 CPU 回退。运行参数限制上下文、图像 token 和线程；退出回收进程。
- `EmbeddedImage` 提供原生 CPU / Vulkan 图片生成与局部重绘，任务排队、取消、超时、临时文件清理以及中文描述翻译。局部结果由原始蒙版本机合成。
- 文字助手和图片引擎分别选择，默认选择保存在用户设置；不把密钥和运行时鉴权写入项目或配置导出。
- 模型中心使用默认模型区、外部连接页、内置设备页；完整连接逻辑拆到 `ConnectionDialog.cpp`。助手顶部常驻选择框，操作日志为独立窗口。
- Agent 按小模型上下文提供相关工具，明确命名工具时只提供相应工具；达到本次命令预算后关闭工具继续总结，仍拒绝违反预算的模型响应。
- 两个构建脚本生成固定模型和运行库的离线包，打包时校验每个资产；安装包及便携 ZIP 包含所有模型和运行库，用户端不需要 Python。
- 图片引擎的 Windows 启动器增加 UTF-8 进程清单，解决中文用户名、安装目录及临时路径导致的模型 / 输出文件访问错误；推理算法和 DLL 代码未修改，最终启动器的 SHA-256 纳入模型包清单。

功能边界：轻量 SD 1.5 图片质量、复杂指令遵循和中文生图文字能力有限。完整 Photoshop 功能、高位深编辑及旧版实施记录中的未完成项没有因本版而自动完成。独立显卡驱动仍由系统提供，软件自动选择可运行的后端，并提供 CPU。

本机真实验证和可重现日志见 [验证记录](VALIDATION.md)。Windows 10、所有 AMD / Intel GPU、干净虚拟机驱动环境与 GitHub Actions 远程执行仍需分别验收。
