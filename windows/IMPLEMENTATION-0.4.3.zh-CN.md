# 映绘 Yinghui 0.4.3

本轮围绕已有本机模型的离线部署、推理复用、开发者设置和品牌更新。文档仍使用 `.comp` v15，已有参数、选区、版本和凭据保持兼容。

- 从本机 Comfy Desktop 的 0.37.0 实例复制 Qwen-Image-2.1 INT8、Qwen3-VL INT8 和 VAE，权重约 17.3 GB；同时复制独立 Python、PyTorch 和必要 Comfy 核心。
- 不复制用户输入、生成结果、连接凭据、用户设置或自定义节点。SHA-256 清单用于复制和发布校验。
- 应用按需启动独立本机服务；临时令牌鉴权、禁用云端节点和自定义节点，退出回收自己的进程。原有 8188 服务不受影响。
- Qwen 2.1 工作流使用 INT8、QwenImage21Cache、CFG 1 和 Euler / simple，默认 25 步；模型进程和缓存跨连续任务复用。
- 生成与编辑都走统一图片引擎；编辑上传当前画面和局部标注，返回后使用本机原始精度蒙版合成。进度来自实际节点和采样事件。
- 新增独立环境安装器和可恢复的开发者脚本编辑；原始权重路径支持固定版本与摘要校验。2511 原始权重入口保留，真实推理尚未验证。
- 简体中文模型中心可调节尺寸、滚动显示，新增离线包定位、设备、尺寸、步数和备用模型设置；操作日志保持独立窗口。
- Windows 展示名称、窗口标题、图标、安装入口、快捷方式和便携程序更新为“映绘 Yinghui”。内部 Compositor 设置与凭据名称保留以便升级。

完整离线便携包运行 `Yinghui.exe`。安装版使用分卷数据，Setup.exe 与所有 .bin 放在同一目录；模型较大，预留至少 35 GB。
Qwen 2.1 为研究 / 评估许可，商用另获授权；官方许可和署名随包提供。轻量模型继续独立可用。

验证证据见 `out/managed-quant-043.json`、`out/tests-043.log`、`out/python-tests-043.log` 和 `out/ui-validation/results.json`。
本机测试不能替代 Windows 10、无 GPU 电脑和干净虚拟机的发布验收；云端服务本轮未调用。
