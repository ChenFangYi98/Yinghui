# 映绘 Yinghui 0.4.4

助手页统一为一个想法输入框，简单 / 专业模式共用。模型列表不按随软件提供或后来下载区分。

- 模型设置用两个勾选项分别启用读图文字模型、图片生成 / 编辑模型。可只用一种，也可协作；未启用的模型不启动、不检测连接、不参与请求。
- 模型设置集中保存模型选择、附图、自动应用 / 预览 / 教学、执行上限、推理设备和开发者设置。助手页只保留输入、区域选择、示例、进度和应用 / 取消。
- 新圈画后自动采用“仅圈选 / 涂选区域”；选择“全部区域”时本次忽略标记，同尺寸编辑后仍保留标记。
- 通过统一 `AIEditCoordinator` 执行图片单模型和双模型任务，使用相同快照、原始蒙版、范围检查、版本保存和一次撤销。
- 只用图片模型时直接处理描述，不暗中启动文字模型。明确参数点、保留指定参数等要求提示启用工具操作，避免重绘近似数值。
- 修复“刚才那块”恢复区域后被全图模式覆盖的问题；修复 Windows 上移动模型目录后校验缓存无法原子替换、反复校验权重的问题。
- 窗口在 100% / 125% / 150% 下保留主要操作，次要信息可滚动。模型配置和操作日志仍是独立窗口。

项目格式保持 v15。完整便携目录复用 0.4.3 的已验证模型和运行库；增量 ZIP 只更新应用与说明，不重复包含权重。
测试和实际模型验证边界见 [验证记录](VALIDATION-0.4.4.md)。
