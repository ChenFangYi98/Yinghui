# Windows 0.4.1：AI 连接与配置窗口修复

本次集中处理千问 API、本机 ComfyUI、模型配置窗口，以及可独立使用的 ComfyUI 中文修图脚本。
项目格式仍为 v15；不更改已有文档数据。

- 千问兼容 API 基础地址、完整 `chat/completions` 地址及工作空间专用地址。对已知混合思考模型关闭思考，避免短连接测试只消耗推理预算；纯思考模型不发送不支持的关闭参数。
- API 的地域鉴权、请求参数、模型、网络错误提供中文原因。服务消息隐藏当前密钥，配置和密钥不会因连接失败而清空。
- ComfyUI 连接检测独立于模型选择；不需要云端密钥。验证 `system_stats`，模型发现包含检查点与 UNET 模型。
- 内置千问图片编辑工作流，匹配本机编码器和 VAE；已有自定义工作流不要求额外填写模型，除非声明了模型映射。
- 模型配置窗口可缩放、最大化、滚动，记住窗口尺寸与列表分隔条；保存按钮保持可见。模型可搜索，长模型名称在展开列表及提示中完整显示。
- 连接测试支持取消过期请求；切换连接、编辑地址、模型、密钥或能力后，旧结果不会更新当前配置。
- 图片连接测试不再误用聊天接口；不会把空回复标为对话成功。
- 独立脚本支持文字生图、单图修改、最多三图参考融合、逐图批量处理、本机蒙版合成与自定义 API 工作流。输出保存新文件，原图保留。

本机已执行千问短回复测试，以及 ComfyUI 脚本和软件内生成/编辑测试；具体范围见 [验证记录](VALIDATION.md)。
使用方法见 [中文快速开始](QUICKSTART.zh-CN.md) 和 [ComfyUI 指南](COMFYUI.zh-CN.md)。

原计划中未交付的高级专业能力仍见 [0.4.0 实施记录](IMPLEMENTATION-0.4.0.zh-CN.md)；本次连接修复不代表完整 Photoshop 功能已经完成。
