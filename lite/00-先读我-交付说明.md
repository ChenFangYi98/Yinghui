# 映绘 Yinghui 0.4.5 开源交付目录

这个文件夹把安装包、源码包、中文使用手册、功能说明和公众号文章放在一起。它是**准备公开发布的文件集合**；代码和文章尚未自动上传到网站。

| 文件 | 用途 |
|---|---|
| `Yinghui-Windows-0.4.5-x64-Setup.exe` 与所有 `Setup-数字.bin` | 完整离线 Windows 安装包。必须一起下载并放在同一文件夹，双击 `Setup.exe` 安装；不要只分享 `.exe`。 |
| `Yinghui-Source-0.4.5.zip` | 可公开托管的源码，包含 Windows C++/Qt 与原 macOS Swift 工程、测试、构建脚本、项目原有 MIT `LICENSE`。不包含个人照片、API 密钥、模型权重、编译产物和用户设置。 |
| `使用手册.zh-CN.md` | 面向第一次修图的用户：安装、常见操作、AI、图层、保存、导出、故障排查。 |
| `功能说明.zh-CN.md` | 功能边界、设计方式、测试证据和未完成事项，适合放在仓库或下载页。 |
| `公众号文章-映绘0.4.5.zh-CN.md`、`宣传配图-软件界面.png` | 可改写发布的公众号稿与实际软件截图。发布前把文末占位文字替换为真实下载、源码链接。 |
| `开源与第三方许可说明.zh-CN.md` | 区分应用源码许可与随包模型许可。 |
| `源码包说明.zh-CN.md` | 开发者的源码目录、Windows 构建与离线模型准备说明。 |
| `SHA256SUMS.txt`、`交付清单.json` | 最终安装分卷、源码和文档的文件大小与 SHA-256，可核对传输完整性。 |

软件源码沿用仓库的 MIT 许可并保留原版权声明。**完整安装包不等同于“所有组件 MIT”**：其中 Qwen-Image-2.1 图片权重依据 Qwen Research License 只授权研究与评估，商用需另行取得授权；ComfyUI、Qt 和其他模型也有独立许可。源码包和安装包可以分别发布，并附上相应的许可证与署名。

使用完整安装版时，Windows 10 22H2 / Windows 11 x64，安装目录建议至少留 45 GB。安装包和已安装程序都保存在同一磁盘时，建议留 90 GB 以上。大看图模型适合充足内存与显存的电脑，低配置请在模型设置中切换 2B。系统驱动、模型质量与复杂画面的判断仍有机器差异。

打开《使用手册》按“五分钟修好一张照片”操作；想继续改程序，看《源码包说明》和 ZIP 里的 `windows/README.md`。发布时在开源仓库说明中保留原 MIT 声明、第三方告知和本次版本的测试边界。
