# Windows 0.3.1 验证记录

日期：2026-10-10。环境：Windows 11 25H2 x64、Intel Core i9-14900K（24 核 / 32 线程）、
128 GB 内存、MSVC 2022 14.44、Qt 6.12.0、Release。

## 已执行

- CTest 核心、升级协议、Agent 和原生界面四套测试通过：74个测试用例（含数据行，不含初始化、清理）。
- 简单／专业模式切换使用同一份文档；自动优化预览不改变修订号，应用后可一步撤销。
- 自由变换角点缩放、旋转手柄与锁定画笔；手动编辑和命令执行都遵守锁定。
- AI 助手完整模拟流程：中文指令 → 工具请求 → 文档副本预览 → 应用 → 一次撤销；请求期间切换文档会丢弃结果。
- 统一命令校验参数范围、未知命令、无效图层、过期文档、事务回滚；在请求期间取消也不会提交结果。
- v14 选区、透明替换和参数保存重开，v13清单及v12 ZIP兼容，十二款预设和全部拼图／海报模板校验。
- 图片局部合成逐像素核对选区外内容；扩图中心在暗角、颗粒等画布相关效果下仍与原画面一致。
- Windows 凭据管理器写入、读取和删除临时测试凭据；配置导出不包含测试密钥。
- 附带 Noto Sans SC 中文回退字体；检查中文字符覆盖，并使用此字体执行界面测试，无需安装系统字体。
- TIFF → 绘图 → 亮度/对比度 → 中文输入法提交文字 → `.comp` 保存重开继续调参 → TIFF / PSD 导出。
- 参数零值、极值、顺序、蒙版、拖动与键盘调参撤销、取消、原始像素和参数分离保存、缓存失效。
- Windows 文件占用导致保存失败时，原文件逐字节保留；自动恢复定时器默认 60 秒，测试缩短定时器后验证后台副本可重开。
- Direct3D 11 显示回读与 CPU 图像一致，最大误差不超过 1 / 255。
- Pillow / tifffile 独立核对 TIFF 的全部 8 种方向、16 位到 8 位转换、多页首页、300 DPI、LZW、透明度和 ICC。
- 独立生成 v1–11 目录清单，全部导入成功。这里只覆盖基础目录迁移，不代表所有旧版效果均逐像素相同。
- psd-tools 仓库的真实 `2layers.psd`、`group.psd`、`1layer.psb`：导入与独立分层重建的最大可见色彩误差为 2 / 255。
- 额外生成隔离组、穿透组、分组蒙版与半透明剪贴堆栈：独立重建 PSD 的最大误差为 1 / 255，合成预览一致。
- 发布目录清除 Qt / 编译工具相关 PATH 后，程序正常启动。安装、启动和卸载使用同一安装脚本、独立测试 AppId，在工作区临时目录验证；本机已安装的 0.1 版本保留。

## 0.3 新增验证

- 精确亮度设置／增加、中文数字、负数和小数、EV、中文百分比宽度缩放、歧义和越界拒绝。
- 相同选区连续“再亮5度”沿用原节点，其他参数及源像素不变；不同选区建立独立节点，选区外像素逐点核对。
- 圈选／区域画笔只修改选区，不画入照片；减去标记和整笔撤销。
- 默认自动应用与一步撤销，保存状态变化不会误取消；文档切换会丢弃旧结果。
- 每轮返回真实工具结果与最新参数，非法计划整次放弃；明确要求不变的参数受到主机约束。
- 模拟语言工具 → 图片引擎 → 本机调色的多轮协作；图片请求上限和选区外文字修改的拒绝路径。
- v14本地版本保留、命名、分支和故障路径；相同源图资产去重，包含历史的项目保存、导入和独立目录恢复。
- 启动短回复检测只调用一次、不附图、不执行工具、64 token预算；模型改变后重新检测。
- MobileSAM编码器、提示／蒙版解码器及ViTMatte经PyTorch与ORT数值对比；固定来源版本和输出SHA-256。
- RTMPose使用官方预导出ONNX，已检查图结构、CPU加载和原生样本推理；未执行重新导出与PyTorch对比。
- 原生本机样本：SAM官方卡车图点选625082像素，约858ms；ViTMatte细化约1260ms；MMPose人物样本输出17个关键点，约407ms；运行中取消约126ms。

模型结果位于 `out/vision-validation/`，模型来源、各项验证范围和哈希见随包 `models/validation.json`。
上述是样本推理与数值验证，不证明所有照片上的分割质量。自动瘦胳膊、多人定位、遮挡和关节保护的变形流程尚未完成。

## 窗口与缩放

`scripts/validate_ui.py` 捕获原生首页和简单模式，以及 125% / 150% 缩放下接近
1366×768 物理像素的窗口。捕获尺寸必须与要求一致，面板可滚动，工具保留中文名称。
结果在 `out/ui-validation/`。已修复首次布局因隐藏面板尚未完成布局而把小窗口撑大的问题。
真实系统显示缩放和中文输入法候选窗口仍需人工检查。

PSD 测试样本固定到上游提交与 SHA-256；测试依赖不随应用发布。
PSD 的合成透明度与预览编码参照 [Adobe 文件格式规范](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)
及 [psd-tools 的独立实现](https://github.com/psd-tools/psd-tools/blob/b58704c1c9c9b2459f961560b1e368dfb102b513/src/psd_tools/api/pil_io.py)。

## 性能基准

同一程序、同一文档：4000×4000、8 个满幅图层，约 512 MB 原始像素；连续改变亮度、对比度和曝光。
测试入口 `tests/Benchmark.cpp`，本轮机器可读结果位于 `out/benchmark-v031.json`。

| 场景 | 本机测量 |
|---|---:|
| 原尺寸 8 图层合成 | 826 ms（0.3为844 ms） |
| 连续 10 次 1024 px 调参预览，包含缓存首次填充 | 646 ms（0.3为681 ms） |
| 800 px 软画笔、约 1000 px 笔画 | 646 ms（0.3为642 ms） |

画笔测量包含 Qt 测试事件投递开销。结果仅代表本机，不作为其他电脑的速度保证。
处理使用 CPU 浮点管线和有界预览缓存，Direct3D 负责显示。
