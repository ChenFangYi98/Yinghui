# 内置本地 AI

映绘 Yinghui 0.4.5 完整安装包和便携目录包含模型权重与推理运行库，无需下载模型、填写密钥或另外安装 Ollama、Python、CUDA Toolkit。已有 0.4.3／0.4.4 完整版仍可覆盖 0.4.5 更新包。

## 更强的千问图片引擎

完整包新增 **Qwen-Image-2.1 INT8**，包括约 17.3 GB 的图片模型、视觉文字编码器和 VAE，以及独立 Python / PyTorch / Comfy 核心。
这些文件从本机已有 ComfyUI 复制，原服务、输入图片、工作流和用户配置不被修改或打包。
在“模型设置”勾选“图片生成 / 编辑模型”并选择 Qwen-Image-2.1；可单独使用，也可勾选读图文字模型协作。
它支持中文文字生图和参考图编辑；局部重绘仍由软件使用原始蒙版保护选区外像素。

模型设置的“图片环境 / 开发者”页可以设置运行设备、输出最长边、步数和备用引擎。
默认 25 步 / 1024 最长边；降低尺寸可以减少耗时。首次校验和加载需要时间，之后复用模型、文本编码和注意力缓存。
软件启动自己的受临时令牌保护的本机服务，不连接或关闭用户原有的 ComfyUI；退出时回收自己的进程。
CUDA 初始化失败会尝试 CPU；大模型 CPU 推理很慢，也需要足够内存。轻量 SD 1.5 可单独选择作为备用。
备用回退会在日志说明；取消任务不会换模型继续生成。硬件、内存和磁盘不足时无法保证任何模型都能运行。

**Qwen-Image-2.1 官方许可仅限研究 / 评估使用，商业用途需另获授权。** 离线包附许可与署名。
页面另外提供 Apache-2.0 的 Qwen-Image-Edit-2511 原始权重安装入口（仅改图，约 58 GB，需联网下载）；此路径未完成本机真实推理验证。
原始权重安装、离线量化图片包、现有轻量模型是独立环境，不修改系统 PATH、Python 或显卡驱动。

## 开发者模式

在“图片环境 / 开发者”启用开发者模式，可以直接修改新引擎的推理 Python 脚本和工作流，再保存、检查语法。
每次保存先备份旧文件；关闭开发者模式立即恢复随软件提供的脚本。自定义 Python 路径仅用于原始权重引擎，量化包使用自带 Python。
改动会在本机执行，请先用小图验证。语法通过不代表画面质量或硬件兼容性通过。原始模型权重保持独立。
“环境与模型目录”保存下载权重、开发脚本和任务数据；“量化图片包”指向安装目录里的 `local-qwen`，可手动定位移动后的包。

## 看图与生成，分别选择

- **文字助手：Qwen3.8 27B UD-Q4_K_M / Qwen3.5 2B Q4**。均支持中文、看图、选区状态和修图工具调用。27B模型与视觉编码器约17.4 GB；2B约1.95 GB，保留为轻量选择。27B是Qwen3.8开放系列中适合此电脑的稠密多模态模型，不是生成图片的模型。[官方模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)
- **生图 / 重绘：内置 SD 1.5 Q4**。约 1.57 GB。支持离线文字生图、图生图与蒙版重绘。原生最长边 512 像素，是轻量模型；精细人像、复杂指令和中文海报文字建议使用已配置的其他图片引擎。中文描述交给选中的文字助手翻译，再送入图片模型。

这两种模型协作完成“看图 → 理解想法 → 调用编辑工具 / 生成图片”。千问多模态助手本身不会输出图像像素；生成模型单独负责像素生成。可以选本地助手配云端图片引擎，也可以云端助手配内置图片引擎。

0.4.4 将选择框移到 **模型设置**，助手页只有一个想法输入框。模型统一展示，不按随包或下载来源区分。
两个勾选项分别启用读图文字模型、图片模型；只选一个单独使用，都选则协作。未勾选的模型不会启动或调用。
设置窗口保存选择、自动应用 / 预览方式、附图和执行上限，重启后记住。已有连接不会被删除，也不会自动切换云端。

## 自动配置运行设备

- 千问：NVIDIA 优先 CUDA，失败尝试 Vulkan，再回退 CPU；其他可用显卡尝试 Vulkan，再回退 CPU。
- 图片模型：Vulkan GPU 优先，失败回退 CPU。
- 运行库已包含在软件目录，设置只作用于软件的子进程。不会修改系统 PATH、CUDA 环境或替换显卡驱动。
- GPU 需要电脑已有兼容显卡驱动；驱动缺失或不可用时尝试 CPU。普通 Windows 软件不能保证替任意显卡安装驱动，因此 CPU 路径仍完整提供。
- 模型设置的 **助手与推理** 页显示轻量模型运行状态，支持自动 / CPU 选择与重新检测。SD 1.5 默认 16 步，Qwen 图片模型默认 25 步。

2B建议至少8 GB内存；27B建议至少32 GB内存，使用独立显卡和SSD更快。完整便携目录包含大图片引擎，约44.2 GB，请至少预留45 GB磁盘空间，下载更新时另预留空间。看图模型默认16384上下文、单任务队列、最多8个CPU线程；整图预览最长边768，原始精度选区留在本机。

0.4.5新增运行期间健康检测、重启后的端口与认证信息刷新，本地接口不会经过系统代理。模型加载超时可单独调整，默认600秒；连接失败不影响基础编辑，也不会自动重复生成或切换云端。
大模型协作时自动交接显存：图片推理前释放看图模型，图片完成后卸载其显存缓存，下一轮按需恢复看图模型并刷新连接。模型权重仍可利用操作系统文件缓存；恢复加载可能需要数十秒。软件内AI任务按顺序运行，排队时可取消，普通编辑继续可用；不会关闭用户另外运行的ComfyUI。

## 独立环境与开发者设置

“助手与推理”页分别设置Qwen看图模型和SD轻量生图环境。Qwen各型号单独保存设备、上下文、CPU线程；可指定匹配的模型包，以及自行编译的llama.cpp CPU / CUDA / Vulkan运行库目录。留空运行库路径使用随包版本；恢复按钮清除运行库覆盖并定位原模型包。
“图片环境 / 开发者”页分别记住Qwen-Image-2.1和Qwen-Image-Edit-2511的设备、步数、最长边及备用引擎设置；两者可共享只读运行库与权重缓存。开发者脚本使用可恢复副本，保存前备份，关闭开发者模式恢复原脚本。
软件子进程隔离Python路径、模型令牌、GPU可见设备和代理等外部变量；不修改系统环境或用户原来的ComfyUI。模型文件启动前校验，修改模型需同步manifest.json中的文件大小与SHA256，并配套正确的视觉编码器。
磁盘损坏、缺少显卡驱动、内存耗尽或不兼容的自定义代码无法保证模型继续推理；软件保留原图，提供CPU、2B或默认环境恢复入口。

## 大致圈选与模型协作

助手页可选“精确圈选”“全部区域”“大致位置”。大致位置模式先结合整图定位对象，再由MobileSAM生成蒙版，最后调用调色或图片编辑；图片引擎获得完整画面和精确蒙版，本机重新合成并检查区域外像素。多个标记分别检查，不将所有标记合成一个大矩形直接重绘。
最多八块标记，定位失败不提交。精确数值要求继续固定原始圈选。每句成功操作保存修改前后版本，下一句使用当前结果；取消、超时和旧修订任务不提交。

首次使用在后台检查文件并加载模型，窗口保持可操作。模型加载时输入的想法会等待；更改图片、取消或改写输入后，旧任务不会自动提交。模型进程随软件退出，异常退出时由 Windows 作业对象回收。

## 用法

1. 打开照片，在模型设置勾选一种或两种模型并选择模型名称。
2. 勾选文字模型后，输入“选中区域变亮5度”即可精确调色；精确数值由本机工具计算，也可离线执行。
3. 输入“把照片提亮一点，颜色自然一些”让助手制定并执行工具步骤。
4. 生成图片：输入“生成一张新的小猫插画”；局部重绘：先圈画或涂出区域，再描述要改成什么。助手自动使用圈选范围，也可切为“全部区域”，本次忽略已有标记。
5. 成功修改保留为可编辑图层或参数，一次任务可整组撤销；继续输入基于当前结果处理。

局部生成结果在本机按原始蒙版重新合成，选区外像素保持原样。图片模型的能力和风格有边界，不能保证每种复杂任务都得到满意结果。

## 模型中心与操作日志

**模型设置** 是独立的大窗口：模型组合、模型列表、助手行为、设备与开发者设置。支持改变窗口大小、最大化、滚动和调整分隔栏；密钥仍存在 Windows 凭据管理器。

**操作日志** 是另外的窗口：显示本次软件运行的实际任务过程，以及当前项目的已提交操作明细。不把模型配置混入日志。已提交编辑、比较、分支和恢复使用“版本”功能；运行时日志不写入项目。
