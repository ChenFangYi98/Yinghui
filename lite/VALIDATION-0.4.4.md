# 映绘 Yinghui Windows 0.4.4 验证记录

2026-10-12，Windows 11 x64、Qt 6.12、MSVC 2022。项目格式仍为 v15，本轮只新增用户设置。

本轮统一助手入口与模型组合：读图文字模型单独使用、图片模型单独使用、两者协作。所有模型统一选择，不按随包或下载来源分组。
助手页不再包含模型选择、附图开关、执行上限或执行方式；这些设置集中在模型设置页，保存后重启保留。

CTest 五组通过，共 127 个实际测试用例，不含初始化 / 清理。证据：`out/tests-044.log`、`out/release/*-tests.xml`。
新增覆盖单图片模型的局部 / 全图连续修改、未启用模型不调用、精确参数拒绝重绘近似、固定选区防止扩大、空选区拒绝、版本恢复、整句撤销 / 重做、三个组合的设置持久保存和新圈画自动切换区域。
完整编辑、格式、旧项目、Agent 和原有内置引擎测试均保留。
另修复 Windows 上模型校验缓存读取后未关闭文件，导致移动模型目录后原子替换失败、反复校验权重的问题。
新增真实文件测试验证目录变更时缓存成功更新、后续重复校验使用缓存，以及模型损坏时仍拒绝加载。

11 个界面截图场景通过，覆盖 100% / 125% / 150% 缩放、1366×768 及小窗口、模型设置与开发者页面。
证据：`out/ui-044.log`、`out/ui-validation/results.json`。截图模式不启动模型或发送网络请求。

本机 Qwen 量化模型的新路由验证见 `out/routing-044.json`：图片模型单独修改选区、单独修改全图、双模型协作修改选区。
测试基于连续修改后的结果，检查区域外像素、标记保留、持久版本、撤销和重做。只用图片模型期间不启动文字助手。
模拟协议覆盖见 Agent 测试；实际云端服务、本轮 Windows 10 与干净虚拟机均未实测。

便携目录和 0.4.3 完整版的增量更新见 `out/update-044.json`。增量 ZIP 不重复包含模型，必须与已有完整包一起使用。
0.4.3 完整安装包的安装 / 卸载验证和模型许可证仍见 [0.4.3 验证记录](VALIDATION-0.4.3.md)。本轮没有重新编译大模型全量安装器。
