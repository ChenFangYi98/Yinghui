## 本机量化千问实际验证

从现有本机 ComfyUI 0.37.0 实例复制独立环境和 Qwen-Image-2.1 INT8 / Qwen3-VL INT8 / VAE。
包清单约 21.50 GB，模型权重约 17.28 GB。未复制自定义节点、用户任务、图片或凭据。
原有本机 8188 服务仍由原进程运行；测试只启动、停止自己的服务。

- 独立 CPU 环境启动约 21.9 秒，令牌鉴权通过；未在 CPU 上完成千问大模型整图推理。证据：`out/private-runtime-cpu-043.json`。
- GPU 实际生图、局部编辑、区域外逐像素保护、取消任务通过。256 与 1024 的实际输出尺寸均符合要求。
- 使用默认 25 步、Euler / simple、CFG 1、INT8 和 QwenImage21Cache。连续任务复用同一进程、模型与缓存。
- 256×256：环境约 13.4 秒，生图约 7.3 秒，局部编辑约 10.1 秒；16384 个选区内像素变化，选区外保持原样。
- 1024×1024：环境约 13.5 秒，生图约 17.4 秒，局部编辑约 32.8 秒；262144 个选区内像素变化，选区外保持原样。
- 在真实采样第 1 步取消，任务未提交；未自动改用其他模型。完成任务后私有输入 / 输出测试图片被清理。

证据：`out/managed-quant-043.json`、`out/managed-1024-043.json` 与对应日志 / PNG。
这些是这台电脑上的合成图片测试，不能表示任意照片、人物、复杂中文排版或其他硬件都达到同样速度和质量。
首次完整文件校验耗时不包含在上述缓存已建立后的环境启动数字中。

## 离线交付与边界

完整便携版为 `dist/Yinghui-Windows-0.4.3-x64.zip`，内含 Qwen 图片包、轻量助手、备用生图模型和运行库。
安装文件位于 `dist/Yinghui-Windows-0.4.3-x64-Installer`；Setup.exe 与所有 .bin 文件必须放在同一目录。
打包时校验归档中的图片包文件 SHA-256，并在仅含 Windows 系统目录的 PATH 下验证应用与独立引擎。
交付与隔离安装 / 卸载证据由 `out/delivery-043.json` 和 `out/install-043.log` 记录。

CI 使用明确标为 Lite 的包测试小体积发行流程；Lite 不含大模型，`PACKAGE-CONTENTS.json` 明确列出实际内容。
本机交付为完整包。Qwen 2.1 的研究许可与署名附在 local-qwen/licenses；商业用途需另获官方授权。
Qwen-Image-Edit-2511 原始权重安装入口、其他 GPU / 无 GPU 完整大模型推理、Windows 10 和干净虚拟机均未完成真实验收。
本轮未调用云端 AI，也未读取、输出或打包账户密钥。
