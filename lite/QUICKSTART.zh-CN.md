# 五分钟开始修图

运行映绘 Yinghui 0.4.5 的完整便携目录中的 `Yinghui.exe`。默认中文和简单模式。
已有 0.4.3 / 0.4.4 完整版也可解压 0.4.5 更新 ZIP，将文件覆盖到原来的程序目录；先退出软件，保留原有模型文件。此次更新包含新的看图权重，体积较大。
0.4.5 完整安装版的 `Setup.exe` 和全部同名前缀的 `.bin` 文件需放在同一文件夹；不要只复制安装器。完整程序约 44.2 GB，请为安装目录预留至少 45 GB；若安装包也在同一磁盘，建议预留 90 GB。旧版完整包仍可使用约 17.4 GB 的更新 ZIP。
先在首页点“打开照片 / 项目”；没有照片可以使用离线示例。

**完整便携目录已内置本地 AI**：Qwen3.8 27B 和 Qwen3.5 2B 可选多模态助手负责看图和操作，SD 1.5 图片模型负责生图 / 重绘。无需单独安装环境。
新增 Qwen-Image-2.1 INT8 图片引擎，自带独立环境，既可生成新图也可修改照片；仅限研究 / 评估，商用需单独授权。
点右侧“模型设置”，在同一份模型列表中选择，不需要区分模型是随软件提供还是之后下载。
勾选“读图文字模型”用于看图、理解想法和调用修图工具；勾选“图片生成 / 编辑模型”用于生图与改图。
只勾选一个就单独使用；两个都勾选时，文字模型规划步骤并在需要时调用图片模型。未勾选的模型不会启动、连接检测或执行任务。
“模型设置”里的“助手与推理”页集中设置自动应用 / 先预览 / 教我操作、是否发送画面、执行上限及 GPU / CPU。
“操作日志”仍是独立窗口。助手页只保留想法、修改区域、示例和执行结果。
在“助手与推理”页选择看图模型：27B理解能力更强，模型与视觉编码器约17.4 GB，建议至少32 GB内存及充足显存；2B约1.95 GB，速度更快。每个模型单独记住设备、线程与上下文。
开发者可以分别设置看图模型包、CPU / CUDA / Vulkan运行库，以及SD模型包；“恢复随软件提供的环境”清除看图运行库覆盖。图片环境页可编辑推理脚本，图片模型的设备、步数和尺寸分别记住。
详见 [内置本地 AI 中文指南](LOCAL-AI.zh-CN.md)。已有云端、ComfyUI 连接和默认选择仍保留。
使用更强图片模型：在模型设置中选择 Qwen-Image-2.1；在“图片环境 / 开发者”页检测环境。
默认 25 步、最长边 1024；显存或内存有限时降低到 512。首次加载较慢，连续任务复用模型缓存。

## 直接说出想法

在右侧“AI 助手”的常驻输入框输入想法，点“开始修改”，或按 Ctrl+Enter。只用图片模型时按钮为“生成 / 修改”。
默认自动应用，成功后会显示“已修改，版本已保存”。每句话可以一步撤销；继续输入会基于当前结果修改。
“先预览再应用”或“教我操作”在模型设置中选择。“教我操作”需要读图文字模型。

- “把照片提亮一点，颜色自然一些。”
- “亮度调到20。”——设置亮度为20个参数点。
- “再亮5度。”——在当前有效亮度上增加5，其他参数保持不变。
- “选区提亮五度，然后对比度增加十度；曝光增加零点五档，饱和度不要动。”——多条精确调色要求一起执行，整句话只需一步撤销。
- “再暗5度。”——在当前亮度上减少5；“亮度20”表示设为20，“对比度＋１０”表示增加10。
- “曝光增加一档。”——增加1 EV。
- “宽度缩小百分之五。”——宽度变为当前的95%，高度保持不变；有区域标记时会提示先清除标记。
- “加上‘周末旅行’四个字，放在右下角。”
- “撤销上一句话。”或“换一种方案。”

**勾选读图文字模型时，精确亮度、曝光等数值指令由软件直接计算，未连接模型也能使用。**
只勾选图片模型时，可以直接输入“生成一张日落海边的插画”或“把圈住的衣服换成蓝色”。不会暗中调用文字模型。
图片模型无法保证亮度滑杆精确增加5点等要求，软件会提示启用文字工具操作，不用重绘近似替代。
未勾选图片模型时，文字助手可以调色、加字和使用本机工具，但不会调用生图 / 重绘。
范围或单位有歧义、数值超限时会提示，不会偷偷截断数值。
支持中文数字、小数和全角数字。为避免把方向理解反，“降低负5度”会要求改写为“降低5度”或“增加负5度”。
精确调色可用逗号、分号或“然后”串联；其中任一步越界，整组不应用。
精确调色与暂不能解析的其他想法混在同一句时，请分开发送；软件不会只执行半句话。
明确说“当前图层”或“整张图片”可以改变作用范围，后续调色沿用该范围；作用范围会显示在输入框上方。

## 只修改照片中的一块

1. 点左侧“圈这里”，围住区域后松手；或者用“涂这里”刷出范围。
2. 蓝色半透明区域表示修改位置。标记不画进照片；“擦掉标记”用于减去范围。
3. 新圈画后，助手自动选择“仅圈选 / 涂选区域”。软件固定本次蒙版，区域外逐像素保持原样；模型不能取消标记或扩大范围。
4. 输入“选中区域变亮5个度”（文字工具操作），或“把这里换成蓝色衣服”（图片改图），再继续输入下一句。
5. 想修改全图，在助手“修改哪里”选择“全部区域”。本次忽略已有标记，标记仍保留，可随时切回局部；也可以清除标记。

**圈得不精确时**：在“修改哪里”选择“大致位置 · 识别完整对象”，输入“把这辆车自然提亮”“把这件衣服换成蓝色”等想法。文字模型结合干净整图、标记图及局部放大图定位目标，本机MobileSAM识别实际边缘；随后只在识别出的区域修改。单独使用图片模型时，根据标记框在本机识别对象，再发送完整图片与精确蒙版。
最多支持八块独立标记；无法定位、遗漏标记或识别范围过大时停止提交，请重新圈画或改用精确圈选。人体部位、重叠物体及透明细节仍可能识别不准，可使用“先预览，再点击应用”。
明确的“选区亮度增加5度”始终按原圈选精确执行，不会因为选了“大致位置”就扩大数值调整范围。

“点选对象”在本机识别被点击的物体。安装包包含已验证模型，不必另装 Python 或模型服务。
识别不准确时，用圈选和涂抹补充。专业模式也可通过命令使用本机边缘细化。
助手同时获得干净画面和蓝色区域标注。小选区的局部图从当前原始清晰度画面裁出，最长边1024像素，
并附原图坐标映射；整图预览最长边2048像素。完整精度蒙版留在本机，局部结果只在该范围内合成。

清除标记后，可以说“刚才那块再亮5度”；保存重开也能找回上次成功修改的范围。
如果对应图层已被移动、旋转或删除，软件会要求重新圈画，防止改错位置。
“当前图层，其他图层不要改”和“选区内修改，不要重新选择区域”会受到本机执行检查。

想轻微收窄胳膊时，先用“点选对象”选中清晰的单个人物，再输入“把人的胳膊变瘦百分之五”。
默认收窄5%；“再瘦百分之二”会在原参数上增加2个百分点，累计上限20%。
肩、肘、腕连接和脸部有保护范围，选区外像素保持原样；在专业模式可继续调强度、关闭或移除效果。
这项本机工具不需要云端图片引擎。多人、严重遮挡或关节定位不可靠时会拒绝执行，请重新选择清晰的人物。

## 第一次配置 AI，以后自动记住

连接窗口支持拖动放大、最大化和中间分隔栏；小屏自动滚动，保存按钮固定在底部，窗口大小会记住。
“账户可用模型”支持输入关键词搜索；长名称可以展开查看完整内容。

1. 点“模型中心”，使用内置模型无需填写密钥；外部服务选择 Kimi 或自己的服务，填写模型、API 地址和密钥。
2. 点“获取模型 / 测试连接”选择账户可用模型；也支持手动填写模型名。
3. 点“保存”。配置写入成功后才显示保存反馈；连接测试失败也会保留配置。
4. 下次打开自动恢复，在后台发送一条极短文字验证对话，不附图、不执行工具；图片连接不会自动生图。

密钥保存在当前 Windows 用户的凭据管理器。**密钥输入框留空表示沿用已保存的密钥**；只有“删除密钥”才会删除它。
配置导出、项目和安装包不带密钥。更换模型后重新检测；连接失败只影响相应 AI 功能。
限流、额度、鉴权、模型不存在、超时和网络错误都有中文提示；需要时点“重试连接”。

Ollama 默认 `http://127.0.0.1:11434`，LM Studio 默认 `http://127.0.0.1:1234/v1`，
这些外部本地语言服务须先自行启动；内置模型由软件自动启动。不会因本地失败自动改用云端。
“执行设置”可调整语言轮次、命令数和图片请求上限；默认分别为4、20、2，失败不会自动重新生成。
取消“附带当前画面”可关闭上传，也会停用需要上传照片的图片编辑。
配置声明支持看图或工具，并不等于这些能力已经真实验证。

**千问：**协议选择 `openai`，北京地域常用地址为 `https://dashscope.aliyuncs.com/compatible-mode/v1`。
密钥与地址的地域必须一致，也支持百炼控制台给出的工作空间专用地址；完整 `chat/completions` 地址会自动转换为基础地址。
本机本次已实际验证 `qwen3.5-plus` 短回复。密钥输入框留空即可继续使用已保存凭据。
地域及工作空间说明见 [百炼官方文档](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。

**ComfyUI：**先启动服务，地址通常为 `http://127.0.0.1:8188`，不需要云端密钥。
未选模型也能检测连接。获取模型后选择 `qwen_image_edit` 系列可使用内置千问图片模板；其他架构使用匹配的自定义工作流。
本次已测试本机模型的真实编辑。独立脚本、拖图片修图、多图融合与批量用法见 [ComfyUI 中文指南](COMFYUI.zh-CN.md)。

## 保存、版本与分享

顶部“撤销 / 重做 / 版本 / 保存项目 / 导出图片”可以直接使用。

- 每次 AI 应用前，先持久保存修改前与修改后状态；保存失败会保留待应用结果，点“应用”可重试。
- “版本”提供缩略图、比较、命名和分支恢复。命名版本不会自动清理；默认保留100个自动状态，本机总预算10 GiB，可调整。
- “换一种方案”从上一次语言任务的基础版本开始，保留当前版本；相同精确数值要求仍得到相同数值。
- Ctrl+S 保存 `.comp` v15 项目，包含原始图层、文字、参数、蒙版、当前区域和上次成功修改的区域。下次打开可以继续修改。
- 文件菜单勾选“保存时包含历史版本”，可以把历史一起带到另一台电脑；默认历史保存在本机。
- 导出 JPEG、PNG 或 TIFF 用于分享或打印。保留 `.comp` 才能继续修改图层。
- 每60秒保存有修改文档的恢复副本；文件菜单“恢复自动保存”可以找回。

手动绘画、文字和参数调整按完成顺序在后台保存版本；连续拖动或一笔合并为一次记录。
保存失败时，在“版本”窗口点重试；正常关闭会等待尚未完成的记录。尚未落盘的队列在异常退出时仍可能丢失。
“比较”既能看整图，也能查看选区附近的100%细节。

AI 请求期间可以缩放、平移和保存。编辑内容、改变选区、切换文档或取消请求会使旧结果失效，防止应用到错误图片。

## 不用 AI 也能修图

连接不可用时会展开“轻松修图”。点击自动优化、十二款滤镜、调节强度、添加中文标题，再导出。
这部分先预览，点“应用效果”才提交。首页还提供各六款拼图和海报模板。
Ctrl+Z 撤销，Ctrl+Y 重做；空格拖动画布，滚轮缩放，Ctrl+0 适合窗口。

## 专业模式和当前边界

右上角切换专业模式，仍是同一份文档。提供图层、分组、锁定、蒙版、剪贴蒙版、混合模式、
画笔、橡皮、仿制、修复、局部模糊／锐化、减淡／加深、涂抹、选区、调整栈、色阶、曲线、中文文字、形状和图层效果。
Ctrl+T 精确变换，Ctrl+Shift+L 锁定／解锁，Ctrl+K 查找命令；双击文字编辑，Ctrl+Enter 完成。
按住Ctrl可多选图层并分组；“选择”菜单提供颜色／亮度范围、扩缩和边缘细化。
局部变形可调整中心、半径、位移和收窄强度，源图保持可编辑；这还不是完整液化工作区。

图片引擎在同一助手中衔接调色和局部重绘；专业模式的“AI 图片”页也提供单独入口。ComfyUI 需另外安装并准备模型。
局部结果保留为新图层，支持透明像素替换；扩图保留可编辑原图层，并固定原有空间效果的处理范围。

**本阶段仍为8位 sRGB。完整液化、RAW、高位深、CMYK、智能对象、路径文字、多画板和完整 Photoshop 功能尚未交付。**
胳膊微调已完成单人样本流程，尚未通过多人、复杂遮挡和各种背景的人像质量验收。
16位 TIFF 会明确转换为8位，多页 TIFF 只导入首页；PSD 导出前显示转换报告。
真实服务与系统验证状态见 [VALIDATION.md](VALIDATION.md)。
