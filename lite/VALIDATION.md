Release 构建成功。CTest 五组全部通过，共 **137 个实际用例**，不含初始化 / 清理：核心 22、升级 21、Agent 47、内置环境 16、界面 31。证据：`out/build-045.log`、`out/tests-045.log`、`out/release/*-tests.xml`。

## 真实本地模型

- `out/embedded-2b-045.json`：Qwen3.5 2B 的短回复、看图、工具调用、局部调色、连续操作、版本保存与重启连接通过。
- `out/approximate-object-2b-045.json`：大致圈在车门附近，结合整图识别整辆车，再执行提亮；区域内 612,740 个像素变化，区域外 0。最初的车门误选样例暴露语义识别问题，修复完整物体 / 部位的识别方式及独立检查轮次后重新通过；不将原失败样例计为成功证据。
- `out/qwen38-045.json`：新 Qwen3.8 27B 在 CUDA 上真实通过文字、红色图片识别、工具调用、局部参数、自然指令和大致位置编辑。首次启动 28.6 秒，重启 8.1 秒；短回复 397 毫秒、颜色识别 359 毫秒。识别整辆车后提亮，区域内 613,307 个像素变化，区域外 0，持久版本保存通过。蒙版人工检查覆盖整辆车。
- `out/routing-2b-045.json`、`out/routing-qwen38-045.json`：各通过图片单模型局部修改、图片单模型全图修改、双模型局部修改三条连续路线。只用图片模型不启动文字模型；局部范围外变化为 0；版本、撤销、重做通过；图片服务拒绝未认证请求。
- `out/approximate-image-045.json`：768×512 实景图片大致圈画 → 27B 结合整图定位汽车 → MobileSAM 识别 → Qwen 图片引擎改红车身 → 看图模型恢复并确认 → 保存版本。图片推理最长边 512、25 步，整体约 44.4 秒；识别区域内 113,337 个像素变化，区域外 0，撤销 / 重做通过。人工检查车身变红且整体场景保持。首次测试发现“只调用一次图片工具”的次数限制把定位也算作唯一编辑，修复计数后完整重测通过。
- 27B 双模型测试中，实际 256 像素 / 25 步图片单模型局部修改约 8.2 秒、全图约 4.5 秒，双模型协作约 30.1 秒，包含看图模型加载与显存交接。图片环境检查约 42.3 秒。结果为此机器单次记录，不代表其他硬件或大尺寸速度。

权重及视觉编码器真实下载后核对 SHA-256。官方模型为 [Qwen/Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B)，官方版本 `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`；量化包为 [unsloth/Qwen3.8-27B-GGUF](https://huggingface.co/unsloth/Qwen3.8-27B-GGUF)，版本 `4ca720788d1e01f1bff70c033e0d0028fd02e502`。文件大小与摘要见 `ai/manifest.json`，许可证随包提供。

## 交付与边界

便携版和更新包核验记录在 `out/update-045.json` 与 `out/delivery-045.json`；便携目录包含新模型及原有运行库。更新 ZIP 需要已有 0.4.3／0.4.4 完整版，不能单独运行。公开交付另外构建 0.4.5 分卷完整安装器；安装器文件摘要和大小列在公开交付目录的 `SHA256SUMS.txt`、`交付清单.json`。

本轮未实测云端服务、Windows 10 / 干净虚拟机、27B 全 CPU 完整编辑和 Qwen-Image-2.1 全 CPU 推理；Qwen-Image-Edit-2511 原始权重路径也未完成真实推理验收。软件只管理自己的图片服务，未修改用户原有 ComfyUI 的文件与环境，也未向其发送停止或卸载请求。

大致位置模式通过模型定位与面积检查降低误选，但不能保证所有对象语义和边缘均准确；复杂人体、遮挡、透明对象、多人和细节修复仍需人工预览。精确圈选始终保持原范围。环境隔离不替代兼容显卡驱动、足够内存 / 磁盘或正确的自定义代码。
